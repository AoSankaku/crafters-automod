# 公開前の機密情報確認

2026-11-16に、`AoSankaku/crafters-automod`をパブリックへ変更する前の確認を行いました。対象は`efdbea8`を基準とするmainの全23コミット、追跡75ファイルと公開前の修正差分です。

## 確認結果

公開を妨げる認証情報・利用者情報・実運用データは検出されませんでした。

| 対象 | 確認内容 | 結果 |
|---|---|---|
| Git履歴 | Gitleaks 8.30.1、全ref・全履歴、抑止コメント無効 | 23コミット、検出0件 |
| 現在の追跡ファイル | 未追跡のローカルデータを含まないスナップショットをGitleaksで検査 | 75ファイル、検出0件 |
| 独自の補助確認 | 140個の履歴blobと現在の追跡ファイルを確認 | 保護対象の識別子・認証情報パターンの検出0件 |
| 独立した内容レビュー | 設定例、過去のルール、テスト、著者情報、第三者データの混入 | 実運用の機密情報は確認されず |
| 著者情報 | 全コミットのメール形式 | GitHubのno-reply形式のみ |
| GitHubの追加公開対象 | main以外のブランチ、タグ、リリース、Actions実行・成果物 | なし |
| GitHub Pages / Wiki | 有効状態 | いずれも無効 |

設定例は置換用の値、テストは合成データです。人間オーバーライドの同梱サンプルは空で、実運用の除外ユーザーや本文フィルターは含まれていません。ローカルの環境ファイル・DB・検証用認証情報・ログは追跡対象に含まれません。

検査ツールは[公式Gitleaks v8.30.1](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1)の配布物を使い、公式チェックサムとのSHA-256一致を確認しました。コードや検出候補を外部の検査サービスへ送信していません。生の検査ログはコミットしていません。

- Gitから`.env.local`や`.env.production`等を除外し、`.env.example`は引き続き追跡可能にしました。
- Dockerのビルドコンテキストから環境ファイルの派生形とローカル検証フォルダを除外しました。
- READMEの取得手順を公開リポジトリ向けに更新しました。

この確認はリポジトリ内容の機密性に関するものです。ソフトウェアの無欠陥や将来の変更の安全性を保証するものではありません。実Misskeyで未検証の範囲はREADMEを参照してください。LICENSEファイルは未設定で、この作業では追加していません。
